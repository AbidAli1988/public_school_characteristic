This dataset contains detailed records of public school characteristics, including student-to-teacher ratios, school types, enrollment numbers, funding details, and additional educational factors. It focuses on data from public schools across various states and counties in the United States, providing insights into school performance, resource allocation, and demographic distributions.

# Motivation
My goal of this project is to understand the patterns and characteristics of public schools in different parts of the United States. Education is important for shaping the future of individuals and communities, and this dataset gives us the chance to look closely at how public schools work.

By analzing this data, I hope to learn more about how things like school funding, the number of students per teacher, and the makeup of different student groups affect education. The dataset includes information like how many students are enrolled, what ethnic groups they belong to, what type of school they attend (such as charter or virtual), and how well the schools are performing.

Looking at these factors it is important for understanding whether all students are getting the same quality of education, and if some schools or areas need more resources. By using this data, we can see how different types of schools in different regions serve their students and if certain groups face challenges due to a lack of resources or support.

In the end, this project aims to provide valuable information to policymakers, school leaders, and community members to help improve education, make sure resources are shared fairly, and create better strategies for improving schools.

# Technologies Used:
To analyze the Public School Characteristics dataset, I used a combination of powerful tools to explore, clean, and visualize the data. I began by using Python in Jupyter Notebook for data analysis. Python’s libraries like Pandas, NumPy, and Matplotlib, and Polty  allowed me to clean and transform the dataset, calculate key metrics, and visualize trends effectively. 

For more visualization experience, I used Power BI to create dynamic dashboards that showcase insights from the data in an engaging way. This visualization allows me for better understanding and easier exploration of the dataset by providing interactive charts and graphs that help users identify significant patterns and trends across different school types, regions, and demographic factors.

# Problems/Hurdles Encountered:

While working with the Public School Characteristics dataset, I faced a few challenges during data cleaning and preparation. One big issue was the missing values in many important columns. I had to find ways to deal with these missing values to make sure the data was complete and accurate. There were also negative values in some columns, like student-to-teacher ratios, enrollment numbers, which didn’t make sense. I had to fix or remove these to get the right data.

Another problem was the inconsistent formats in the data. Some columns had different ways of showing the same information, which made it hard to compare and analyze the data correctly. I had to clean and standardize the data to make sure everything was in the same format.

### Usage

This dataset can be used for:

- **Education equity analysis**: Comparing the quality of education across different regions and school types.
- **School performance research**: Analyzing the relationship between student-teacher ratios, funding, and academic outcomes.
- **Demographic analysis**: Studying the diversity and enrollment patterns of students in public schools.
- **Policy-making**: Informing decisions on resource allocation and strategies for improving public education.
- **Trend analysis**: Investigating the impact of school characteristics on student success over time.
